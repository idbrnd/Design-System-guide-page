# 아이콘

두 가지 방식으로 사용할 수 있습니다.

**개별 컴포넌트 import (권장)** — 사용한 아이콘만 번들에 포함됩니다(트리셰이킹).

```tsx
import { ChevronDownIcon } from '@idbrnd/design-system'

<ChevronDownIcon size={20} color="var(--semantic-text-sub)" />
```

**이름 기반 `Icon` 래퍼** — 이름 문자열로 렌더링합니다.
단, import하는 순간 **모든 아이콘이 번들에 포함**되므로 번들 크기가 중요하면 개별 import를 사용하세요.

```tsx
import { Icon } from '@idbrnd/design-system'

<Icon name="chevron-down" size={20} />
```

## 공통 Props

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `size` | `number \| string` | `24` | 아이콘 크기 (px) |
| `color` | `string` | `currentColor` | 색상. CSS 변수 사용 가능 |
| `style` | `CSSProperties` | — | 추가 인라인 스타일 |

> `dashboard-*` 아이콘은 **고정 색상**이 내장되어 있어 `color`가 적용되지 않습니다.
