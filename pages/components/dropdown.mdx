# Dropdown

`children`을 트리거로 사용하는 범용 드롭다운 컴포넌트입니다.
버튼, 텍스트, 아이콘 등 원하는 엘리먼트를 트리거로 자유롭게 사용할 수 있습니다.

<Demo>
  <BasicDropdownDemo />
</Demo>

```tsx
import { Dropdown, OutlineButton } from '@idbrnd/design-system'
import type { DropdownOption } from '@idbrnd/design-system'

const options: DropdownOption[] = [
  { label: '수정', value: 'edit', icon: <WriteIcon size={16} /> },
  { label: '복제', value: 'duplicate', icon: <CopyIcon size={16} /> },
  { label: '삭제', value: 'delete', icon: <TrashIcon size={16} /> },
]

function DropdownExample() {
  const handleSelect = (option: DropdownOption) => {
    console.log('선택:', option.label)
  }

  return (
    <Dropdown options={options} onSelect={handleSelect} width={200}>
      <OutlineButton variant="assistive">메뉴 열기</OutlineButton>
    </Dropdown>
  )
}
```

## 검색 기능 + 선택 상태 표시

`selectedValue`에 현재 선택된 옵션의 `value`를 전달하면 일치하는 항목에 선택 스타일과 `aria-selected`가 적용됩니다.

<Demo>
  <SearchDropdownDemo />
</Demo>

```tsx
function SearchDropdown() {
  const [selected, setSelected] = useState<DropdownOption | null>(null)

  return (
    <Dropdown
      type="search"
      options={options}
      onSelect={setSelected}
      selectedValue={selected?.value}
      width={240}
    >
      <OutlineButton variant="assistive">{selected?.label ?? '선택하세요'}</OutlineButton>
    </Dropdown>
  )
}
```

## Props

| Prop | 타입 | 기본값 | 설명 |
| --- | --- | --- | --- |
| `children` | `ReactNode` | — | **(필수)** 드롭다운 트리거 엘리먼트 |
| `options` | `DropdownOption[]` | — | **(필수)** 드롭다운에 표시할 옵션 배열. `{ label, value, icon?, disabled? }` 형태 |
| `onSelect` | `(option: DropdownOption) => void` | — | **(필수)** 옵션 선택 시 호출되는 콜백 |
| `selectedValue` | `string` | — | 현재 선택된 옵션의 `value`. 선택 스타일 및 `aria-selected` 적용 |
| `type` | `'basic' \| 'search'` | `'basic'` | `'search'` 시 드롭다운 상단에 검색 입력란 표시, 실시간 필터링 |
| `align` | `'left' \| 'center'` | `'left'` | 옵션 텍스트 정렬. `center`일 때 아이콘은 좌측, 라벨은 중앙 정렬 |
| `content` | `boolean` | `false` | `true` 시 옵션의 `icon`이 라벨 좌측에 표시 |
| `width` | `number` | — | 드롭다운 목록 너비(px). 미지정 시 트리거 너비에 맞춤 |
| `textColor` | `string` | — | 옵션 라벨 텍스트 색상 커스터마이징 (예: `'#6366f1'`) |
| `disabled` | `boolean` | `false` | `true` 시 트리거 클릭이 무시됨 |
| `customStyle` | `CSSProperties` | — | 루트 엘리먼트 인라인 스타일 (`style` 대신 사용) |

### DropdownOption

| 필드 | 타입 | 설명 |
| --- | --- | --- |
| `label` | `string` | **(필수)** 옵션에 표시되는 텍스트 |
| `value` | `string` | **(필수)** 옵션의 고유 식별 값 |
| `icon` | `ReactNode` | 옵션 라벨 좌측 아이콘. `content={true}`일 때만 렌더링됩니다 |
| `disabled` | `boolean` | `true`이면 클릭이 차단되고 비활성 스타일이 적용됩니다 |

## 유의사항

- Select와 달리 트리거 UI를 직접 제공해야 합니다 (`children`).
- Select는 선택 상태를 `DropdownOption` 객체로 관리하지만, Dropdown은 `selectedValue` 문자열로 관리합니다.
- 드롭다운 목록은 `document.body`에 포탈로 렌더링됩니다.
- 긴 옵션 라벨은 말줄임 처리되며, hover 시 툴팁으로 전체 텍스트가 표시됩니다.
- 열림/닫힘 시 fade + scale 애니메이션이 적용됩니다.
- 옵션에 `disabled: true`를 지정하면 해당 옵션이 클릭 불가 상태로 표시됩니다.

## Select vs Dropdown 비교

| 기능 | Select | Dropdown |
| --- | --- | --- |
| 트리거 | 내장 (라벨 + 버튼 + chevron) | `children`으로 직접 제공 |
| 선택 값 관리 | `selectedValue: DropdownOption \| null` | `selectedValue: string` |
| 라벨/설명/에러 | 지원 | 미지원 (직접 구현) |
| 사이즈 변형 | large / medium / small | 트리거에 따라 자유 |
| 사용 시나리오 | 폼 내 셀렉트 필드 | 컨텍스트 메뉴, 액션 드롭다운 등 |
