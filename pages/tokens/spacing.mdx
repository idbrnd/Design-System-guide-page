# 간격

픽셀 단위 치수 토큰입니다. 간격·크기·라운드 등 수치가 필요한 곳에 사용합니다.
행을 클릭하면 `var(--이름)`이 복사됩니다.

```css
.card {
  padding: var(--16);
  gap: var(--8);
}
```
