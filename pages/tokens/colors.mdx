# 색상

모든 색상은 CSS 변수로 제공됩니다. 스와치를 클릭하면 `var(--이름)` 형태로 복사됩니다.

```css
.my-element {
  color: var(--semantic-text-default);
  background: var(--main-5);
}
```

> 모든 색상 변수는 `--이름-rgb` 짝 변수(쉼표로 구분된 RGB 값)도 함께 제공되어
> `rgba(var(--main-50-rgb), 0.5)` 형태로 투명도를 조절할 수 있습니다.
