# IDB Design System

React 기반 IDB 디자인 시스템 컴포넌트 라이브러리 `@idbrnd/design-system`의 공식 가이드입니다.

설치부터 컴포넌트 사용법, 디자인 토큰, 아이콘까지 실제 렌더링되는 예제와 함께 안내합니다.

<LandingDemoButton />

## 무엇이 있나요?

- **[시작하기](/getting-started)** — 설치, 스타일 로드, TypeScript 설정
- **[디자인 토큰](/tokens/colors)** — 색상 팔레트, 타이포그래피, 간격 스케일
- **[컴포넌트](/components/buttons)** — 30여 개 컴포넌트의 라이브 데모와 Props 문서
- **[아이콘](/icons)** — 190개 아이콘 검색과 사용법

## 기술 스펙

| 항목      | 내용                                 |
| --------- | ------------------------------------ |
| 패키지    | `@idbrnd/design-system`              |
| React     | `^18.3.1` (peerDependency)           |
| 모듈 형식 | ESM                                  |
| 스타일    | CSS Modules + CSS 변수 (디자인 토큰) |
| 타입      | TypeScript 선언 파일 내장            |
